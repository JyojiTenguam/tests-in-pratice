# 🧠 Tests in pratice

Projeto destinado a implementar e aprender sobre testes automatizados utilizando a biblioteca **Jest**, como parte dos exercícios da formação em Desenvolvimento Web da Trybe.

## ✨ Demonstração

> Este projeto é composto por uma série de funções que são validadas por meio de testes automatizados, com o uso da biblioteca **Jest** para garantir o comportamento correto das funções implementadas.

## 💡 Sobre

Este projeto visa praticar a criação de testes automatizados utilizando **Jest** para validar funções desenvolvidas em **JavaScript**. Durante o desenvolvimento, foram implementadas funções para resolver problemas de lógica de programação, que posteriormente foram validadas por testes para garantir que estivessem funcionando corretamente.

## 🛠️ Habilidades desenvolvidas

- Implementação de testes automatizados utilizando **Jest**
- Escrita de funções em **JavaScript** para resolver problemas lógicos
- Aplicação de boas práticas para garantir a qualidade do código
- Prática de desenvolvimento orientado a testes (TDD)

## 🧪 Tecnologias utilizadas

- JavaScript ES6+
- Node.js
- Jest

## 🚀 Como rodar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/JyojiTenguam/tests-in-pratice.git

2. Acesse a pasta do projeto

```bash
cd tests-in-pratice
```

3. Instale as dependências
```bash
npm install
```
